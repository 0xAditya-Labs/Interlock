# Benchmark Results

This directory contains auto-generated benchmark output files.

**Committed files:**
- `BENCHMARK_REPORT.md` — The final human-readable benchmark report (committed)

**Gitignored files:**
- `phase-a-raw.json` — Raw Phase A ramp data (machine-specific, not committed)
- `phase-b-raw.json` — Raw Phase B latency data (machine-specific, not committed)

To regenerate all results, run from the project root:
```bash
npm run benchmark
```
